Create a new story spec for the given feature. The argument is the story slug (e.g. `/new-story wallet-connect-button`).

1. Read `docs/agent/stories/_template.md` to get the spec format.
2. Ask the user for: the user story (who / what / why), acceptance criteria, and which team owns it.
3. Write the completed spec to `docs/agent/stories/<slug>.md`, filling in all sections. Use Given/When/Then format for every AC.
4. Report the path of the new file and remind the user to link the GitHub issue number before opening a PR.
